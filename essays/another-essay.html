Another Essay Title
January 2024

Another essay starts here. This is a template you can copy whenever you want to write something new.

The process is simple:

1. Copy this file
2. Rename it (use-dashes-like-this.html)
3. Change the title
4. Write your content
5. Add a link in essays.html and index.html

That's it. No build process. No dependencies. Just HTML.
